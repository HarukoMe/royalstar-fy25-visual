# IF2 Conduct

An evidence-informed study conductor for **CII IF2 General Insurance Business**, Chapters **1–6** (syllabus 2026 learning outcome **1.1** — insurance products).

This is not a PDF reader, flashcard deck, or LMS. Once a Focus Session starts, the engine chooses the next reading, prediction, retrieval, distinction or scenario from the curriculum model and your demonstrated performance.

## What is modelled

- Motor, health, package, property, pecuniary and liability products
- Concept-level learner model (production vs recognition, confident errors, successive relearning)
- Persistent spaced review across sessions (browser `localStorage`)
- Attention adaptations that change the *learning move*, not the chrome
- Source locators on facts, items and tutor text
- Audio as the same engine speaking the current step (Web Speech)

Chapters 7+ are not ingested.

## Run

```bash
npm install
npm test
npm run dev
```

Open the printed URL. Use **Focus** to study. The atlas outside the session shows gaps, mix-ups, due retrievals and a separate exam-readiness overlay — not a single percentage of “done”.
